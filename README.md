# بورتفوليو عبدالرحمن سامي

موقع أعمالي في قسمين: **التسويق** و**العمارة والتصميم**. الصور بتتعرض في معرض، والفيديوهات بتشتغل كاملة جوه الموقع. الموقع عربي وإنجليزي.

الموقع مبني HTML/CSS/JS عادي من غير أي build، فأي تعديل بتعمله push على GitHub، Vercel بينشره لوحده في أقل من دقيقة.

---

## كل اللي هتعدّله في 3 ملفات بس

| الملف | فيه إيه |
|---|---|
| `assets/content/profile.js` | اسمك، صورتك، النبذة، الخبرة، الأرقام، التواصل، ملفات الـ CV |
| `assets/content/marketing.js` | مشاريع التسويق وتصنيفاتها |
| `assets/content/architecture.js` | مشاريع العمارة وتصنيفات الفراغات |

والميديا:

| الفولدر | فيه إيه |
|---|---|
| `assets/media/marketing/` | صور وفيديوهات التسويق |
| `assets/media/architecture/` | صور وفيديوهات العمارة |
| `assets/docs/` | ملفات الـ PDF للتحميل (السيرة الذاتية والبورتفوليو) |

## إضافة مشروع جديد (خطوة بخطوة)

**1. ارفع الملفات** في الفولدر الصح، مثلاً:
```
assets/media/architecture/office-01.jpg
assets/media/architecture/office-02.jpg
```
خلّي الأسامي إنجليزي، من غير مسافات، بحروف صغيرة.

**2. افتح ملف القسم** (`architecture.js` أو `marketing.js`). جوه `projects: [ ... ]` انسخ أي بلوك `{ ... },` والصقه في المكان اللي عايز المشروع يظهر فيه، وعدّله:

```js
{
  id: "office-dammam",                 // اسم فريد، إنجليزي، من غير مسافات
  category: "offices",                 // نوع الفراغ (شوف الجدول تحت)
  title: { ar: "مكاتب إدارية بالدمام", en: "Offices in Dammam" },
  description: { ar: "وصف قصير", en: "Short description" },
  client: "اسم العميل",                // اختياري
  year: 2026,                          // اختياري
  media: [
    "office-01.jpg",
    { file: "office-02.jpg", caption: { ar: "الاستقبال", en: "Reception" } },
    "office-walkthrough.mp4",
  ],
},
```

**3. احفظ وارفع (push).** هتلاقي المشروع في الموقع بعد دقيقة.

### مشروع فيديو
اكتب اسم الفيديو أول حاجة في `media`:
```js
media: ["new-ad.mp4"],
```
ولو حطيت صورة بنفس الاسم (`new-ad.jpg`) جنب الفيديو، هتبقى صورة الغلاف. لو مفيش، الموقع بياخد أول لقطة من الفيديو.

مقاس الفيديو (طولي أو عرضي) الموقع بيعرفه لوحده.

### فيديو من YouTube أو Vimeo أو Google Drive
حط الرابط مكان اسم الملف:
```js
media: ["https://youtu.be/XXXXXXXXXXX"],
```
وده الأفضل للفيديوهات الطويلة أو الكبيرة (أكبر من 50MB). لو على Google Drive، خلّي الملف "Anyone with the link".

### أنهي تبويب المشروع هيظهر فيه؟
- أول عنصر في `media` **فيديو** → يظهر في تبويب **الفيديوهات**.
- أول عنصر **صورة** → يظهر في تبويب **الصور**.
- لو المشروع فيه الاتنين → يظهر في التبويبين.

**العمارة:**

| المفتاح | بيظهر كـ |
|---|---|

### إضافة تصنيف جديد
في نفس الملف، جوه `categories`، ضيف سطر:
```js
offices: { ar: "مكاتب", en: "Offices" },
```
وبعدين اكتب `category: "offices"` في المشروع. زرار الفلتر هيظهر لوحده، وترتيب الأزرار هو ترتيب السطور في `categories`.

## تعديل، حذف، إخفاء، ترتيب

| عايز | تعمل إيه |
|---|---|
| **تعدّل** اسم أو وصف | عدّل النص في البلوك |
| **تحذف** مشروع | امسح البلوك بتاعه كله من `{` لحد `},` |
| **تخفي** مشروع مؤقتاً | ضيف `hidden: true,` جوه البلوك |
| **ترتّب** المشاريع | حرّك البلوك فوق أو تحت. الترتيب في الملف = الترتيب في الموقع |
| **ترتّب** صور مشروع | رتّب الأسامي جوه `media` |
| مشروع يظهر في **الصفحة الرئيسية** | ضيف `featured: true,` |
| **كارت أكبر** | `size: "wide",` (عريض) أو `size: "tall",` (طولي، مناسب للريلز) |
| **صورة غلاف مختلفة** | `cover: "اسم-الصورة.jpg",` |
| **تغيّر غلاف القسم** | `cover` و `coverVideo` في أول ملف القسم |

## الملف الشخصي (`profile.js`)
- **الصورة الشخصية:** بدّل `assets/media/profile.jpg` بصورة بنفس الاسم.
- **الـ CV:** بدّل `assets/docs/Abdelrahman-Samy-CV.pdf` بنسخة أحدث بنفس الاسم.
- **الأرقام:** في `stats`. الرقم اللي قيمته `"projects"` بيتحسب لوحده من عدد المشاريع.
- **الخبرة:** ضيف وظيفة جديدة في أول `experience`.

## نصايح للصور والفيديو
- **الصور:** JPG بعرض حوالي 1600 بكسل كفاية (أقل من 500KB للصورة).
- **الفيديو:** MP4 (H.264). فيديوهات الآيفون (.mov / HEVC) **مش بتشتغل على Chrome**، فحوّلها الأول. أسهل طريقة بـ HandBrake (اختار Preset "Fast 1080p30")، أو بالأمر ده:
  ```
  ffmpeg -i input.mov -c:v libx264 -crf 23 -pix_fmt yuv420p -c:a aac -movflags +faststart output.mp4
  ```
- **GitHub بيرفض أي ملف أكبر من 100MB.** الفيديوهات الكبيرة ارفعها على YouTube (Unlisted) أو Vimeo وحط الرابط.

## لو حاجة مظهرتش
افتح الموقع، واضغط F12، وروح لتبويب **Console**. الموقع بيكتب هناك تحذير لو فيه `id` متكرر، أو مشروع من غير ميديا، أو تصنيف مش موجود في القائمة. ولو صورة مش ظاهرة، غالباً اسم الملف في `media` مختلف عن اسمه الحقيقي (انتبه للحروف الكبيرة والصغيرة).

## تجربة على جهازك
```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

## النشر
الموقع منشور على Vercel ومربوط بالريبو ده. أي push على الفرع الأساسي بينشر تلقائياً.

## السيرة الذاتية (CV)
السيرة الذاتية اللي على الموقع هي `assets/docs/Abdelrahman-Samy-CV.pdf`: صفحة واحدة A4 بالإنجليزي، فيها العمارة والتسويق مع بعض. زرار "حمّل السيرة الذاتية" في الموقع بينزّلها هي.

ولو احتجت تقدّم على وظيفة متخصصة، فيه كمان نسختين منفصلين (مش ظاهرين في الموقع):
- `assets/docs/Abdelrahman-Samy-CV-Architect.pdf` للعمارة بس.
- `assets/docs/Abdelrahman-Samy-CV-Visual-Content.pdf` للتسويق بس.

المصدر في فولدر `cv/` (`combined.html` و `architecture.html` و `marketing.html`). عشان تعدّل: غيّر النص في ملف الـ HTML، وبعدين شغّل `node cv/build.mjs` (محتاج Playwright) عشان يطلع PDF جديد. ولو النص زاد عن صفحة، السكريبت هيقولك.
